# sample_images/

Place sample retinal fundus images here for testing the Streamlit app
without needing the full APTOS 2019 dataset.

Accepted formats: `.jpg`, `.jpeg`, `.png`

You can download freely-licensed fundus images from:
- https://www.kaggle.com/competitions/aptos2019-blindness-detection/data (requires Kaggle login)
- https://www.ias-iss.org/ojs/IAS/article/view/1155 (Messidor public samples)
